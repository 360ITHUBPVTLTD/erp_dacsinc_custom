Order Flow dashboard — tabs by role — Dacsinc ERP

Order Flow dashboard — tabs by role

Which tabs and sub-tabs of the Order Flow dashboard each role sees. A role is shown a tab only when it may open the documents on that tab, so this sheet follows the document access. Click a cell to change it: hidden → ✓ → A → hidden. Showing a sub-tab also shows its main tab, and hiding a main tab hides its sub-tabs. ✓ shows the tab with no action buttons; A also allows its create, submit and approve buttons.

✓ can view A can view and act (create, submit or approve from the tab) hidden ✓ changed since the last save
