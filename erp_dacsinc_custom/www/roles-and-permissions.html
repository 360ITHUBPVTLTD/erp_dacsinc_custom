Role Profiles — what to assign a new user

A Role Profile is the one-click bundle you pick on User > Role Profile when creating someone new. Pick the row matching their job title; you never need to hand-pick individual roles.

Anyone hired for one of these jobs should get Role Profile set to the matching name below — not individual roles added by hand. If their role profile ever needs another permission, add it to the profile (or to role_permission_matrix.py if it's a matrix-wide change), not to the individual user.

Managing this live

This page is the reference. To actually assign Role Profiles, create users, reset passwords, or edit profile details, use Roles & Permissions in the desk (/app/roles-and-permissions) — a live, editable panel restricted to System Manager / Admin / Super Admin. A user can be given several Role Profiles there at once (e.g. Merchandiser + POS User), which isn't possible on the standard User form.
Passwords are never visible to anyone, at any permission level — Frappe only ever stores a one-way hash. A System Manager can set a new password directly; Admin / Super Admin can only send the user a reset-link email instead.
